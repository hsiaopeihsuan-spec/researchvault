# ResearchVault｜研究文獻與筆記工作台

ResearchVault 是使用原生 HTML、CSS、JavaScript 和 IndexedDB 製作的靜態研究資料管理網站。可部署至 GitHub Pages，不需後端或 API 金鑰。

## V1.1：文獻附件
- 文獻可**同時保留網址及一個 PDF／DOCX 附件**；可上傳、更換、移除或下載，PDF 可嘗試在新分頁預覽。
- 附件上限 **20 MiB／檔**，只存於目前瀏覽器 IndexedDB，不會上傳 GitHub 或同步到其他裝置。
- 原有 IndexedDB 資料會從資料庫版本 1 自動升級至版本 2，保留文獻與筆記。
- JSON 備份版本 2 包含附件內容（Base64），檔案可能很大。支援舊版 schemaVersion 1 還原，但舊備份不含附件。

## 功能
- 文獻 CRUD、閱讀狀態與標籤。
- 結構化「文獻閱讀筆記」及「研究構想筆記」。每篇筆記至少關聯一篇存在的文獻，可連結多篇。
- 文獻與筆記雙向查看。為避免孤立筆記，刪除仍被引用的文獻前必須先解除或重新分配筆記關聯。
- 全站關鍵字搜尋、類型與標籤篩選。
- IndexedDB 本機保存；JSON 匯出與驗證後確認整份覆蓋還原。
- 專業研究儀表板與響應式介面。

## 本機啟動
使用本機 HTTP 伺服器（避免 `file://` 模組與瀏覽器儲存限制）：

```bash
cd ResearchVault
python -m http.server 8000
```

在瀏覽器開啟 `http://localhost:8000`。若 Windows 未安裝 Python，可使用 VS Code 的 Live Server。

## GitHub Pages 部署
1. 建立 GitHub repository，將此專案的 `index.html`、`css/`、`js/`、`AGENTS.md` 和 `README.md` 上傳到 repository 根目錄。
2. 到 Settings → Pages → Build and deployment，選擇 Deploy from a branch、`main`、`/(root)`，儲存。
3. 等待 Pages 部署後開啟顯示的網站網址。
4. GitHub Pages 只提供網站程式碼；研究資料保存在每位使用者當下瀏覽器的 IndexedDB 中，不會上傳到 GitHub。

## JSON 匯入注意事項
- 匯入支援 `schemaVersion: 1`（不含附件）與 `schemaVersion: 2`（包含附件）的備份。
- 先驗證完整資料、模板與文獻關聯，再顯示覆蓋確認。
- 還原會取代現有文獻、筆記和附件；請先匯出目前備份。
- 目前限制單次匯入檔案不超過 100 MiB。
- 內建模板定義跟隨網站程式；匯入含未知模板版本的備份會拒絕，以免資料不可讀。

## 測試步驟（需在實際瀏覽器執行）
1. 新增一篇文獻，刷新頁面確認仍存在。
2. 新增文獻閱讀筆記，選擇該文獻，儲存並刷新。
3. 嘗試取消筆記唯一的文獻關聯，應被拒絕。
4. 嘗試刪除仍被筆記引用的文獻，應被拒絕。
5. 搜尋筆記欄位文字，測試類型和標籤篩選。
6. 匯出 JSON；再透過資料管理頁選取備份並確認還原。
7. 新增 PDF 或 DOCX 附件，刷新後查看／下載，並測試替換、移除與 20 MiB 限制。
8. 匯出包含附件的 V2 JSON，再還原並核對檔案內容；測試舊版 V1 JSON 還原會清除目前附件。
9. 用無效 JSON 或移除 `relatedPaperIds` 的備份測試匯入，應被拒絕且不影響原資料。
10. 在手機尺寸測試表單、搜尋與導覽。
11. 依照 `AGENTS.md` 新增「實驗紀錄」模板並回歸測試。

## 已知限制
- 不支援 PDF／Word 內容解析、雲端同步、帳號系統、AI 自動摘要。
- 搜尋採用讀取後在瀏覽器過濾，適合課程展示及一般個人文字資料；超大資料量需進一步優化。
- 原生 IndexedDB 的跨分頁同時編輯沒有衝突合併機制；請避免多分頁同時修改同一資料。
- 瀏覽器清除網站資料、隱私模式或儲存政策可能導致本機資料消失，請定期備份。


## V1.2：可選擇載入示範資料
- 研究總覽新增「載入示範資料」按鈕。訪客按下並確認後，會在**自己的瀏覽器**加入 3 篇虛構文獻及 2 篇結構化筆記，供測試搜尋、標籤、筆記模板與文獻關聯。
- 所有示範資料均標記「示範資料」，**不是**真實學術論文或研究結果；不含 PDF／Word 附件。
- **不會**覆蓋原有資料，不會自動載入，也不會將使用者資料傳送到 GitHub。再次載入時若已存在示範資料 ID，會拒絕重複新增。
- 如需清除示範資料，請在研究筆記頁先刪除相關示範筆記，再到文獻資料庫刪除示範文獻；操作前可先 JSON 備份。
